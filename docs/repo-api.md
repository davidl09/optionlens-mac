Notes from ingestion:
- Chain parser keeps only standard roots (symbol itself; BRK.B→BRKB root; SPX/SPXW, NDX/NDXP, RUT/RUTW, VIX/VIXW).
- Nasdaq dividend histories only cover Nasdaq-listed securities; other listings get theirs from IBKR's adjusted closes (`dividends_derived`, source `ibkr-adjusted`) and Questrade's current dividend (source `questrade`). repo.dividends reads the merged set (Nasdaq, else IBKR, else Questrade; `discrepancy` when amounts differ > $0.01; INTEGRATION.md §6 "Dividends"). Without a trailing year of dividends, services estimate q from put-call parity (implied forward).
- option_eod has no PK index (delete-then-insert per (date,symbol)).
- Index history: SPX, RUT close-only; XSP OHLC; NDX starts at first EOD.
- Extra table alert_fires (per-symbol cooldowns).
- Only one process may open the DuckDB file: stop the server before CLI data commands on the same DATA_DIR.
- Finality boundary: jobs/_util.FINAL_DELAY_MIN=20, session_close(day), final_since(day)=close+20min. metrics_daily rows are only written before final_since or by the eod sweep; later fetches refresh option_latest/quotes only.

Chain sources and the IBKR bridge (settings.chain_sources, default ("ibkr-bridge","questrade"); server-side sources are swept only while available):
- sources.chain_source: ChainSource protocol (name; unavailable()->reason|None; status()->dict; async keepalive(); async fetch_chain(symbol, final=False)->ChainSnapshot, NotListed); REGISTRY {"questrade": factory}; server_source_names()/server_sources()/available(); tag(name) ("ibkr-bridge"->"ibkr"); preference()->tags in order. sources.questrade: auth (TokenManager/TokenStore), ratelimit (RateGate), client (QuestradeClient), mapping (pure JSON->models), source (QuestradeSource); instance().
- jobs.precedence: Quality(source, final, realtime, quoted); of_snapshot/of_metrics_row/of_archive; replaces(existing,new,order=None): same source always; else final > real-time > quoted > source order. sources.osi: parse_osi(osi); format_osi(symbol,expiry,right,strike) (PM roots SPXW/NDXP/RUTW); standard_roots(symbol).
- jobs.chains.store_chain(snap, now, final=False, *, source=None): option_latest/quotes (unless a newer chain is stored), the session's metrics row (per jobs.precedence; keeps stats-only values the chain lacks), and with final (now >= session close) the session's option_eod archive (per jobs.precedence). store_underlying_stats(session_date, stats:[{symbol,price,change_pct,volume,call_volume,put_volume,call_oi,put_oi,iv30,hv30}], source)->n: fills metrics rows (chain-derived values win; HV windows from stored closes), iv30 also -> vol_history. sweep(symbols=None, final=False) over every available server-side source (RuntimeError when none is configured; universe + cash indices), sweep_final() (close+20m..20:00 ET), sweep_fill() (after-hours fill of symbols without a chain since the session's open, once per 6 h); refresh_chain(src, sym, final) applies hooks.chain_preparers (services.ingest.complete_chain: IV borrowed from another source, else computed) before store_chain; eod() = archive_unarchived(day) + daily bars from quotes + on_eod hooks, 20:05 ET.
- jobs.catchup: catchup_sessions(now,n=10)->[date] (sessions whose push window, until 20:00 ET, ended); missing_eod(symbols,sessions)->{sym:[date]}; reconstruct_rows(symbol,day,bars,spot,r,q)->rows (pure: IV by BS inversion of the close at the session close, greeks from it); store_reconstructed_bars(symbol, bars:[{expiry,strike,right,date,close,volume,...}], source)->n (r: stored rate else settings; q: trailing dividend yield when dividends cover the year else 0).
- jobs.bridge_plan (parts of GET /api/ingest/wants): chain_universe(now)->[sym] (watchlists + opened in 7 days + top settings.chain_universe_size by option volume); chain_universe_want(now)->{symbols,max_age_s,expiries,moneyness}; underlying_stats_want(now)->{symbols,max_age_s} (universe from open to 20:00 ET on trading days); eod_chains_want(now)->{session_date,symbols,not_before,deadline} (chain universe + EOD_INDICES without an IBKR archive); option_bars_want(now,record=True)->[{symbol,sessions,expiries,moneyness}] (sessions without archive whose underlying close is stored; each offered at most 3 times, 6 h apart).
- jobs.ondemand.ensure_fresh(sym,max_age_s=120): records the visit; refetches a stale chain from the first available server-side source (Questrade when connected), else serves the stored chain.
- jobs._util.eod_deadline(day) -> 20:00 ET of the session.
